## ADR-002. Взаимодействие модулей на бэкенде

### Статус

Принято.

### Проблема

Прямое обращение одного модуля к таблицам БД другого модуля создает жесткую связанность.

### Решение

Взаимодействие модулей выполнять через внутренние интерфейсы сервисов.

Например:

```text
VisitModule -> IMembershipValidationService
```

### Последствия

Положительные:

- модули слабее связаны;
- проще писать unit-тесты.

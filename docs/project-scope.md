# 2. Назначение и границы проекта

## 2.1. Назначение системы

Разрабатываемая программная система предназначена для автоматизации учета клиентов, абонементов, тренировок и посещений фитнес-центра.

Пользователь системы (сотрудник рецепции) должен иметь возможность:

- добавлять, удалять и редактировать данные клиентов;
- искать клиентов по ФИО и телефону;
- оформлять клиенту абонемент с выбором типа;
- видеть автоматически рассчитанную дату окончания абонемента;
- просматривать список активных и завершенных абонементов;
- отмечать факт посещения клиентом фитнес-центра;
- формировать отчеты по проданным абонементам и посещаемости.

Сотрудник с правами администратора должен иметь возможность:

- добавлять и изменять типы абонементов;
- управлять учетными записями пользователей системы;
- просматривать расширенные финансовые отчеты.

---

## 2.2. Основные объекты предметной области

В системе выделены следующие основные сущности:

- клиент;
- абонемент;
- тип абонемента;
- посещение;
- сотрудник (пользователь);
- роль пользователя.

Примеры типов абонементов:

- Разовое посещение;
- Месячный безлимит;
- Годовой с бассейном.

---

## 2.3. Границы проекта

### В систему входит

1. Ведение базы клиентов.
2. Оформление и учет абонементов.
3. Автоматический расчет срока действия абонемента.
4. Регистрация посещений.
5. Проверка актуальности абонемента при визите.
6. Отчеты по клиентам, абонементам, посещаемости.
7. Авторизация пользователей в системе.
8. Хранение истории операций.

### В систему не входит

В рамках курсового проекта не реализуются:

- реальные банковские платежи;
- интеграция с терминалами оплаты;
- интеграция с турникетами и электронными замками;
- мобильное приложение для клиентов;
- онлайн-расписание и запись через сайт;
- автоматическая отправка SMS и e-mail.

Эти функции могут быть добавлены при дальнейшем развитии проекта.

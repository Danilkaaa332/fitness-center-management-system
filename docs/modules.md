# 4. Перечень модулей системы

На стороне серверного API выделено четыре основных функциональных модуля.

| Модуль | Ответственность |
|---|---|
| `CustomerModule` | Хранение информации о клиентах |
| `MembershipModule` | Оформление и управление абонементами |
| `VisitModule` | Регистрация посещений и контроль сроков |
| `ReportModule` | Формирование статистических отчетов |

Дополнительно используется точка входа (FastAPI Host), которая принимает HTTP-запросы от WPF-клиента и передает их соответствующим модулям.

---

## 4.1. CustomerModule

Отвечает за работу с профилями клиентов.

Основные функции:

- регистрация клиента;
- получение данных клиента;
- изменение контактных данных;
- поиск по базе.

Пример состояний клиента:

```text
Active
Blocked
```

---

## 4.2. MembershipModule

Отвечает за абонементы.

Основные функции:

- создание абонемента;
- расчет дат начала и окончания;
- отмена абонемента;
- предоставление данных об активности абонемента.

Модуль взаимодействует с:

```text
CustomerModule
```

---

## 4.3. VisitModule

Отвечает за отметки посещений.

Основные функции:

- регистрация нового посещения;
- проверка актуальности абонемента;
- хранение истории визитов.

Пример состояний посещения:

```text
Registered
Cancelled
```

---

## 4.4. ReportModule

Отвечает за формирование сводной информации.

Основные функции:

- агрегация данных о посещаемости;
- расчет проданных абонементов за период.

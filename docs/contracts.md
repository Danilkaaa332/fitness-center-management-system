# 10. Описание API

WPF-клиент взаимодействует с системой через HTTP API.

Предполагаются следующие основные точки входа.

| Метод | Адрес | Назначение |
|---|---|---|
| `GET` | `/api/v1/customers` | Получение списка клиентов |
| `POST` | `/api/v1/customers` | Регистрация клиента |
| `POST` | `/api/v1/memberships` | Оформление абонемента |
| `GET` | `/api/v1/memberships/{id}` | Получение абонемента |
| `POST` | `/api/v1/visits` | Регистрация посещения |
| `GET` | `/api/v1/reports/visits` | Получение отчета |

Контракт API на последующих этапах может быть дополнительно описан средствами OpenAPI (Swagger).
